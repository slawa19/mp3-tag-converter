# 🎵 MP3 Tag Converter: Windows-1251 → UTF-8

Рекурсивно обходит каталоги с MP3-файлами, исправляет кодировку тегов ID3 (Windows-1251 → UTF-8) и опционально переименовывает файлы с «кракозябрами».

> Актуальная версия: **v6**

---

## 📦 Зависимости

```bash
pip install mutagen chardet tqdm
```

| Библиотека | Назначение |
|------------|------------|
| [mutagen](https://mutagen.readthedocs.io/) | Чтение и запись ID3-тегов |
| [chardet](https://github.com/chardet/chardet) | Определение кодировки |
| [tqdm](https://github.com/tqdm/tqdm) | Прогресс-бар *(опционально)* |

---

## 🚀 Быстрый старт

```bash
# 1. Проверка без изменений (рекомендуется запустить первым)
python convert_tags.py "D:\Музыка" --rename --dry-run --log --workers 8

# 2. Применить исправления
python convert_tags.py "D:\Музыка" --rename --log --workers 8
```

## 🔧 Флаги

| Флаг | По умолч. | Описание |
|------|-----------|----------|
| `--dry-run` | — | Только показать что изменится, не сохранять |
| `--rename` | — | Включить переименование файлов с кракозябрами |
| `--no-tags` | — | Не трогать теги (используется вместе с `--rename`) |
| `--rename-confidence` | `0.80` | Порог уверенности chardet для имён файлов (0.0–1.0) |
| `--log` | — | Сохранить лог в файл рядом с каталогом |
| `--verbose` | — | Подробный вывод (все файлы, включая без изменений) |
| `--workers N` | `1` | Число потоков для параллельной обработки |

## ⚙️ Как это работает

1. **Обнаружение кракозябр**: скрипт пробует перекодировать строку из `latin-1` в `cp1251` через `chardet`, затем проверяет наличие кириллицы в результате.
2. **Тройная защита от ложных срабатываний**:
   - Строка должна кодироваться в `latin-1`
   - `chardet` должен определить `cp1251` с уверенностью ≥ порога
   - После перекодировки должна появиться кириллица (`U+0400..U+04FF`)
3. **Теги** сохраняются в формате `ID3v2.3` с кодировкой `UTF-8` (или `UTF-16` для совместимости со старыми плеерами).
4. **Многопоточность**: используется `ThreadPoolExecutor` — эффективно для IO-bound операций чтения/записи тегов.
