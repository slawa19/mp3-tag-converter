# 🎵 MP3 Tag Converter: Windows-1251 → UTF-8

Рекурсивно обходит каталоги с MP3-файлами, исправляет кодировку тегов ID3 (Windows-1251 → UTF-8) и опционально переименовывает файлы с «кракозябрами».

> Актуальная версия: **v6**

---

## 📦 Зависимости

```bash
pip install mutagen chardet tqdm
```

| Библиотека | Назначение |
|------------|------------|
| [mutagen](https://mutagen.readthedocs.io/) | Чтение и запись ID3-тегов |
| [chardet](https://github.com/chardet/chardet) | Определение кодировки |
| [tqdm](https://github.com/tqdm/tqdm) | Прогресс-бар *(опционально)* |

## 🚀 Быстрый старт

```bash
# 1. Проверка без изменений (рекомендуется запустить первым)
python convert_tags.py "D:\Музыка" --rename --dry-run --log --workers 8

python convert_tags.py "D:\Музыка" --rename --log --workers 8
```

## 🔧 Флаги

| Флаг | По умолч. | Описание |
|------|-----------|----------|
| `--dry-run` | — | Только показать что изменится, не сохранять |

| `--workers N` | `1` | Число потоков для параллельной обработки |

## ⚙️ Как это работает

1. **Обнаружение кракозябр**: скрипт пробует перекодировать строку из `latin-1` в `cp1251` через `chardet`, затем проверяет наличие кириллицы в результате.
2. **Тройная защита от ложных срабатываний**:
   - Строка должна кодироваться в `latin-1`
   - `chardet` должен определить `cp1251` с уверенностью ≥ порога
   - После перекодировки должна появиться кириллица (`U+0400..U+04FF`)
3. **Теги** сохраняются в формате `ID3v2.3` с кодировкой `UTF-8` (или `UTF-16` для совместимости со старыми плеерами).
4. **Многопоточность**: используется `ThreadPoolExecutor` — эффективно для IO-bound операций чтения/записи тегов.

## Безопасность и совместимость

- Python 3.9+; версия `chardet` ограничена веткой 5.x: смена детектора в 7.x меняет результаты распознавания.
- Поиск учитывает `.mp3` и `.MP3`, пропускает символьные ссылки и служебные каталоги с префиксом `.` / `@`.
- Перед записью тегов создаётся полная копия исходного файла `<имя>.tag-backup`. Существующая копия никогда не перезаписывается: при необходимости повторной правки файл пропускается с ошибкой. Копии требуют свободного места; не удаляйте их до проверки результата.
- Для отката восстановите исходный файл из `.tag-backup` (если применялось `--rename`, сначала восстановите прежнее имя по журналу).
- Рекомендуется сначала запускать `--dry-run`, затем исправление **без `--rename`**, если проблема только в отображении тегов. Автоматическое распознавание эвристическое и не гарантирует исправление всех типов повреждения.
- Исправленные теги сохраняются как ID3v2.3 / UTF-16. FLAC, M4A и другие форматы этим скриптом не обрабатываются.
- При ошибках процесс возвращает ненулевой код завершения.

Проверки: `python -m unittest -v test_converter`.

## Расширенная проверка всей библиотеки

`repair_library.py` обходит поддерживаемые Mutagen форматы (MP3, FLAC, M4A, Ogg/Opus, WMA, WAV/AIFF, APE/WavPack и другие) и проверяет текстовые значения тегов. ID3: текстовые фреймы, комментарии/тексты песен, описания и URL; бинарные данные обложек не перекодируются. Неподдерживаемые/повреждённые файлы отражаются в отчёте. Это не обещание восстановления произвольно утраченных символов.

```bash
# Аудит без изменений
python repair_library.py /path/to/music --report audit.jsonl
# Исправления с отдельной НОВОЙ папкой полных резервных копий
python repair_library.py /path/to/music --apply --report repair.jsonl --backup-root /path/outside/music/backups-run1
```

Требуется `ffmpeg` в PATH для проверки SHA256 аудиопотоков до/после записи. Если проверка после записи не проходит, исходный файл автоматически восстанавливается. Для CP1251 используется либо подтверждение декодированного значения в исходном пути, либо высокая уверенность детектора без смеси алфавитов. UTF-8 mojibake исправляется через `ftfy.fix_encoding`. Неоднозначные случаи записываются в `suspects`, без принудительной перекодировки (важно для правильных западноевропейских названий).

`--overrides reviewed.json` принимает проверенные вручную замены вида `{ "relative/file.mp3": { "TIT2.text": { "old": "damaged", "new": "confirmed" } } }`. Замена выполняется только при совпадении старого значения. Ничего не выводится автоматически из имени файла; потерянные буквы требуют подтверждённого источника. Инструмент не удаляет записи MA и не сбрасывает его базу.

Тесты: `python -m unittest -v test_converter test_repair_library`.
